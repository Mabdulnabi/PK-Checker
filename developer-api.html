Developer API

Connect your own website or system to PK Checker. Send a document, follow its status, and download the official Turnitin similarity and AI reports, all from your code.

Base URLhttps://www.pkchecker.com/v1
Auth: Bearer API key Rate limit: 60 req / min Cost: 1 check per file Beta: available to selected accounts

Developer API access

Every request is authenticated with your own API key, and each submitted file uses one check from your PK Checker balance, exactly like a file uploaded from the dashboard.

  1. Sign in and open My account → Developer API.
  2. Create a key and copy it (it is shown only once).
  3. Send it in the Authorization: Bearer YOUR_API_KEY header.

How it works

1

Submit a document

POST /v1/scan/submit with the file. You get a file_id.

2

Check the status

GET /v1/scan/status until the status is Completed (poll every 10–20 seconds).

3

Download the reports

GET /v1/scan/download for the similarity PDF, and with report_type=ai for the AI PDF.

Endpoints

POST/v1/scan/submit1 check / file

Submit a file (or raw text) for a Turnitin similarity check, with or without AI detection. Send the request as multipart/form-data.

  • Formats: PDF, DOCX, DOC, TXT, ODT · up to 50 MB
  • Similarity: up to 50,000 words · AI detection: up to 30,000 words (longer files get the similarity report only)
  • AI detection languages: English, Spanish, Japanese, Arabic · minimum 300 words
  • Raw text: at least 40 words
FieldTypeDescription
fileFileRequired*The document. *Or send text instead.
textStringOptionalRaw text to check when no file is sent (min 40 words).
service_typeStringOptionalBoth (default: similarity + AI), Turnitin AI (same as Both), or Turnitin Plagiarism (similarity only, needs similarity-only checks in your balance).
exclude_quotes0 / 1OptionalExclude quoted text from the similarity score. Default 0.
exclude_biblio0 / 1OptionalExclude the bibliography / references. Alias: exclude_bibliography. Default 0.
exclude_citations0 / 1OptionalExclude in-text citations. Default 0.
exclude_small_matches0 / 1OptionalExclude matches shorter than small_match_threshold words. Default 0.
small_match_thresholdInteger 8–250OptionalWord threshold for small matches. Alias: exclude_words. Default 8.
custom_idStringOptionalYour own order or user id (up to 100 characters). Returned in every response.
serverStringOptionalAccepted for compatibility (s1); ignored.
Response · 200
{
  "success": true,
  "file_id": "PK1-261124-21",
  "filename": "Research_Thesis.docx",
  "custom_id": "order_9812",
  "status": "Pending",
  "message": "File submitted successfully and queued for Turnitin scanning",
  "slots_remaining": 14
}

If the check service is busy, the file is kept and sent automatically as soon as possible; the response is the same (status: "Pending") with a note in message.

GET/v1/scan/status?file_id={file_id}Free

The state of a file, its scores and the report links. Status values: Pending (waiting to be sent), Processing (being checked), Completed, Failed (with an error field).

{
  "success": true,
  "file_id": "PK1-261124-21",
  "filename": "Research_Thesis.docx",
  "custom_id": "order_9812",
  "status": "Completed",
  "similarity_score": 14,
  "ai_score": 2,
  "word_count": 4850,
  "download_url": "https://www.pkchecker.com/v1/scan/download?file_id=PK1-261124-21",
  "ai_download_url": "https://www.pkchecker.com/v1/scan/download?file_id=PK1-261124-21&report_type=ai",
  "completed_at": 1727443320
}

ai_score is null when the AI report shows "*%" (20% or less), when AI detection was not requested, or when it could not run (word limit, language).

GET/v1/scan/download?file_id={file_id}&report_type={type}Free

Downloads the official Turnitin report as a PDF (Content-Type: application/pdf).

FieldTypeDescription
file_idStringRequiredThe file_id from the submit response.
report_typeStringOptionalplagiarism (default, similarity report) or ai (AI writing report).
GET/v1/account/balanceFree

The checks available in your PK Checker balance (active packages).

{
  "success": true,
  "status": "Active",
  "available_credits": 14,
  "total_credits": 20,
  "used_credits": 6

🗂
48-hour storage. Reports are kept for 48 hours after delivery and then deleted. Download them to your own storage after Completed.

HTTP response codes

CodeStatusMeaning
200OKRequest processed successfully.
400Bad RequestMissing or invalid parameters (no file or text, wrong format, file over 50 MB…).
401UnauthorizedMissing or invalid Bearer API key.
402Payment RequiredNo checks left in your balance for this type of check.
404Not FoundUnknown file_id, or the report does not exist.
409ConflictThe report is not ready yet.
410GoneThe report was deleted (48 hours after delivery).
422UnprocessableThe check service did not accept the file. No check was used.
429Too Many RequestsOver 60 requests a minute, or the same file just failed (wait a minute).
503UnavailableThe check service is temporarily unavailable. No check was used.

Every error response is JSON: {"success": false, "error": "…"}.

Integration snippets

# 1) Submit
curl -X POST "https://www.pkchecker.com/v1/scan/submit" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@thesis.docx" \
  -F "service_type=Both" \
  -F "exclude_quotes=1" \
  -F "exclude_biblio=1" \
  -F "custom_id=order_9812"

# 2) Status
curl "https://www.pkchecker.com/v1/scan/status?file_id=PK1-261124-21" \
  -H "Authorization: Bearer YOUR_API_KEY"

# 3) Download (similarity, then AI)
curl -o similarity.pdf "https://www.pkchecker.com/v1/scan/download?file_id=PK1-261124-21" \
  -H "Authorization: Bearer YOUR_API_KEY"
curl -o ai.pdf "https://www.pkchecker.com/v1/scan/download?file_id=PK1-261124-21&report_type=ai" \
  -H "Authorization: Bearer YOUR_API_KEY"
import time, requests

API = "https://www.pkchecker.com/v1"
HEAD = {"Authorization": "Bearer YOUR_API_KEY"}

# 1) Submit
with open("thesis.docx", "rb") as f:
    r = requests.post(f"{API}/scan/submit", headers=HEAD,
                      files={"file": f},
                      data={"service_type": "Both", "exclude_quotes": 1, "custom_id": "order_9812"})
r.raise_for_status()
file_id = r.json()["file_id"]

# 2) Wait for the result
while True:
    s = requests.get(f"{API}/scan/status", headers=HEAD, params={"file_id": file_id}).json()
    if s["status"] in ("Completed", "Failed"):
        break
    time.sleep(15)

# 3) Download
if s["status"] == "Completed":
    pdf = requests.get(f"{API}/scan/download", headers=HEAD, params={"file_id": file_id})
    open("similarity.pdf", "wb").write(pdf.content)
    if s.get("ai_download_url"):
        ai = requests.get(f"{API}/scan/download", headers=HEAD, params={"file_id": file_id, "report_type": "ai"})
        open("ai.pdf", "wb").write(ai.content)
else:
    print("Failed:", s.get("error"))
<?php
$api = "https://www.pkchecker.com/v1";
$key = "YOUR_API_KEY";

// 1) Submit
$ch = curl_init("$api/scan/submit");
curl_setopt_array($ch, [
  CURLOPT_POST => true,
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_HTTPHEADER => ["Authorization: Bearer $key"],
  CURLOPT_POSTFIELDS => [
    "file" => new CURLFile("thesis.docx"),
    "service_type" => "Both",
    "custom_id" => "order_9812",
  ],
]);
$res = json_decode(curl_exec($ch), true);
$fileId = $res["file_id"];

// 2) Status
$ch = curl_init("$api/scan/status?file_id=" . urlencode($fileId));
curl_setopt_array($ch, [CURLOPT_RETURNTRANSFER => true, CURLOPT_HTTPHEADER => ["Authorization: Bearer $key"]]);
$status = json_decode(curl_exec($ch), true);

// 3) Download when Completed
if ($status["status"] === "Completed") {
  $fp = fopen("similarity.pdf", "w");
  $ch = curl_init("$api/scan/download?file_id=" . urlencode($fileId));
  curl_setopt_array($ch, [CURLOPT_FILE => $fp, CURLOPT_HTTPHEADER => ["Authorization: Bearer $key"]]);
  curl_exec($ch);
  fclose($fp);
}
// Node.js 18+ (built-in fetch, FormData and Blob)
import { readFile, writeFile } from "node:fs/promises";

const API = "https://www.pkchecker.com/v1";
const HEAD = { Authorization: "Bearer YOUR_API_KEY" };

// 1) Submit
const form = new FormData();
form.append("file", new Blob([await readFile("thesis.docx")]), "thesis.docx");
form.append("service_type", "Both");
form.append("custom_id", "order_9812");
const sub = await (await fetch(`${API}/scan/submit`, { method: "POST", headers: HEAD, body: form })).json();

// 2) Wait for the result
let s;
do {
  await new Promise(r => setTimeout(r, 15000));
  s = await (await fetch(`${API}/scan/status?file_id=${encodeURIComponent(sub.file_id)}`, { headers: HEAD })).json();
} while (!["Completed", "Failed"].includes(s.status));

// 3) Download
if (s.status === "Completed") {
  const pdf = await fetch(`${API}/scan/download?file_id=${encodeURIComponent(sub.file_id)}`, { headers: HEAD });
  await writeFile("similarity.pdf", Buffer.from(await pdf.arrayBuffer()));
}
